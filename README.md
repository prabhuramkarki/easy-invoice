# Easy Invoice

Easy Invoice is a simple tool that uses OCR to extract text from invoices and convert it into structured data. Users can export the extracted information directly into a CSV file, making invoice management faster, accurate, and easy to analyze or share.

## Features

- Extract text from invoices using OCR  
- Convert invoice data into structured format  
- Export extracted data to CSV  
- Save time and reduce manual errors
