# Easy Invoice

[![Python](https://img.shields.io/badge/python-3.10+-blue)](https://www.python.org/)  

Easy Invoice is a user-friendly tool that uses OCR to extract text from invoices and convert it into structured data. Users can export the extracted information directly into a CSV file, making invoice management faster, accurate, and easy to analyze or share.

---

## Features

- Extract text from invoices using OCR  
- Convert invoice data into structured format  
- Export extracted data to CSV  
- Supports PDF and image invoices (JPG, PNG)  
- Reduces manual errors and saves time
